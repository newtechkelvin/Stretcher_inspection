如何對接真實 Google Drive & Sheets

本原型 (Prototype) 展示了完整介面與前端流程。若需要實行將數據**直接寫入貴公司的 Google Drive 及 Sheets**，最簡單免成本的方法是使用 **Google Apps Script (GAS)** Web App Webhook。

運作架構 (Architectural Diagram):

手機/網頁前端 ➔ 發送 JSON (相片base64 + 簽名 + 欄位) ➔ Google Apps Script ➔ 自動建資料夾 & 生成 PDF ➔ 存入 Google Drive & 寫入 Google Sheet

Google Apps Script 後端範例程式碼 (100% 免費)：

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  
  // 1. 寫入 Google Sheet 紀錄
  sheet.appendRow([new Date(), data.hospital, data.stretcherId, data.inspector, data.signerName, data.overallStatus]);
  
  // 2. 於 Google Drive 建立專屬資料夾
  var parentFolder = DriveApp.getFolderById("YOUR_GOOGLE_DRIVE_FOLDER_ID");
  var yearFolder = getOrCreateSubFolder(parentFolder, new Date().getFullYear().toString());
  var hospFolder = getOrCreateSubFolder(yearFolder, data.hospital);
  var recordFolder = hospFolder.createFolder(data.refNo + "_" + data.stretcherId);
  
  // 3. 儲存相片與簽名
  if(data.signature) {
    var sigBlob = Utilities.newBlob(Utilities.base64Decode(data.signature.split(',')[1]), 'image/png', 'signature.png');
    recordFolder.createFile(sigBlob);
  }
  
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}

留空則使用預設 LocalStorage 模擬儲存模式。
